1. Textbook Knowledge Graphs from OpenAI prompt created for some concepts from mathematics and physics - could be a classroom teaching assistant - 27 May 2026
-------------------------------------------------------------------------------------------------
New python source file AITextbookKnowledgeGraph.py has been added to NeuronRain Grafit repositories that queries OpenAI gpt-5.5 for a user defined concept from textbook and creates a knowledge graph for the concept in DOT format and renders it as image file by prompt query template:
    query="Create a knowledge graph for "+concept+" in DOT format and render it"
Following 3 queries were posed to gpt-5.5 on concepts from mathematics and physics textbooks:
    ai_textbook_knowledgegraph(concept="Michelsen Morley Interferometer")
    ai_textbook_knowledgegraph(concept="Berry-Esseen Central Limit Theorem")
    ai_textbook_knowledgegraph(concept="Proof of Lorentz transformation and Special relativity")
and text format of knowledge graphs are logged to testlogs/AITextbookKnowledgeGraph.log.27May2026 and following are images rendered for above concept queries by ChatGPT prompt that could assist as a teaching slide in classroom:
	testlogs/michelson_morley_knowledge_graph.png
	testlogs/berry_esseen_knowledge_graph.png
	testlogs/lorentz_special_relativity_knowledge_graph.png
